# Концепт-арт «Гномья крепость» (issue #2)

Векторные концепты (SVG — легко открыть в браузере и импортировать в Godot):

- `board_mine_concept.svg` — шахта дварфов: квадратное поле, выходы со всех четырёх сторон.
  Идея выходов: каменные арки-порталы с цветной подсветкой стороны (север — синий кристалл,
  юг — янтарный фонарь, запад — рудная тележка, восток — знамёна клана). Через выход
  выталкиваются добытые камни за пределы поля.
- `characters_dwarves_concept.svg` — 4 гнома-игрока: различимые цвета (рыжий/синий/жёлтый/зелёный),
  каска, топор, борода; поза «в обводке» под плейсхолдер-квадрат 56px.
- `characters_goblins_concept.svg` — гоблины-лазутчики: зелёная кожа, красные глаза,
  появляются на зелёных клетках после 12-го хода, убивают соседа в 4 направлениях.

Палитра согласована с `scripts/board.gd` (TILE_COLORS) и `characters/dwarf.gd` (COLORS).
