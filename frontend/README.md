# Frontend — «Гномья крепость» (Godot 4.x, GDScript)

Веб-версия настолки: экспорт в HTML5/WASM (`export_presets.cfg`, CI — `.github/workflows/godot-web.yml`).

## Структура
- `scenes/main_menu.tscn` — главное меню: кнопки «Выбрать комнату», «Создать комнату»,
  «Локальный мультиплеер» + выбор размера поля;
- `scenes/room_list.tscn` — список комнат для подключения (лобби до 4 игроков);
- `scenes/board.tscn` — игровое поле (6×6 / 8×8 / 10×10), пошаговый локальный мультиплеер,
  кнопка «Закончить ход», кнопка карты;
- `characters/character.gd` → `dwarf.gd`, `goblin.gd` — иерархия персонажей;
- `game_config.gd` — **конфиг**: размер поля, n шагов за ход, x карт за ход;
- `autoload/game_state.gd` — singleton: сообщает ноде поля режим игры (LOCAL_MP/ONLINE);
- `cards/tags.md`, `cards/first_cards.md` — теги и первые версии карт;
- `art/concept/`, `art/cards/` — концепт-арт шахты с выходами с 4 сторон, гномов, гоблинов, арт карт.

## Управление (локальный MP)
WASD/стрелки — шаги текущего гнома (не более MOVES_PER_TURN), карта «Прыжок на 2» —
кнопка под HUD, «Закончить ход» — по кнопке или автоматически после исчерпания шагов.
Ход переходит к следующему игроку. Плейсхолдеры контрастны: градиентный задник,
цветные квадраты персонажей с обводкой, тайлы разных цветов.

Запуск редактором: `godot --path frontend`. Сетевые комнаты требуют запущенного backend (`../backend/build/server`).
