# Теги карт — «Гномья крепость» (issue #2)

Словарь тегов. Каждый тег описывает механику карты; параметр `x` — число клеток.
Все определения едины для фронтенда (Godot) и бэкенда (C++).

| Тег | Что делает карта | Описание механики |
|---|---|---|
| `jump_x` | Прыжок на x клеток | Перемещение персонажа на дистанцию x клеток по прямой с игнорированием препятствий (стен, камней, грибов, кристаллов, других персонажей). Приземление — на первую свободную клетку за прыжком; если её нет в пределах поля, персонаж остаётся на месте. |
| `push_x` | Толчок на x клеток | Толкает объект перед собой (камень/коробку/драгоценный камень) на x клеток, пока путь свободен. Вытолкнутый за край поля камень засчитывается как добытый. |
| `mine_free` | Бесплатная добыча | Даёт 1 строительный камень без перемещения (с жёлтой клетки спавна камней). |
| `swap` | Меняются местами | Два гнома меняются позициями мгновенно (препятствия игнорируются). |
| `laser_red` | Красный лазер | В этом ходе толкания разрушают грибы и кристаллы (см. README: красный лазер). |
| `laser_green` | Зелёный лазер | Проход сквозь стены в направлении луча на время хода; выход из стены обязателен до конца хода. |
| `laser_yellow` | Жёлтый лазер | Толкаемые камни уничтожаются полностью; можно столкнуть камень в другого игрока (тот возрождается в углу). |
| `build_1` | Постройка | Добавляет 1 камень в счётчик постройки крепости из инвентаря гнома. |
| `trade` | Торговка | Обмен 1 драгоценного камня на 10 обычных строительных камней у торговца. |
| `peek_deck` | Разведка колоды | Посмотреть верхние 3 карты колоды, вернуть в любом порядке. |
| `extra_move` | Дополнительный ход | +1 шаг в этом ходу (сверх n из game_config). |
| `goblin_stop` | Стопор гоблинов | Гоблины не двигаются в следующем раунде. |

Правило использования: за ход можно применить не более `CARDS_PER_TURN` карт (файл `game_config.gd`).
